Primeros pasos

Descripción de las carpetas de su sitio web

  • /css - Archivos para la presentacion de su sitio web
  • /fonts - ICONOS del sitio web
  • /webfonts - Fuente de letras
  • /img - Imagenes de su sitio web
  • /js - Archivos con scripts en lengujaes JQuery y JS No editar!

Nota: no modificar el archivo enviar.php ya que es el algoritmo que permite el funcionamiento del formulario

Modificar textos

Siempre escribir dentro de las comillas " " o dentro de los parrafos con el: 

<p>ESTE ES UN TEXTO QUE SERÁ CAMBIADO AHORA POR MONET</p>

Quedaría así

Nota: si aparece un simbolo así < es porque hizo falta una comilla o el cierre de la etiqueta </>
