Primeros pasos

Descripción de las carpetas de su sitio web

  • /css - Archivos para la presentacion de su sitio web
  • /fonts - ICONOS del sitio web
  • /webfonts - Fuente de letras
  • /img - Imagenes de su sitio web
  • /js - Archivos con scripts en lengujaes JQuery y JS No editar!

Nota: no modificar el archivo enviar.php ya que es el algoritmo que permite el funcionamiento del formulario

Como Ingresar a su Panel de Admnistrador

Ingresar al archivo HTML para editar sitio web

Modificar textos

Siempre escribir dentro de las comillas " " o dentro de los parrafos con el: <p></p> donde p se refiere a parrafo

<p>ESTE ES UN TEXTO QUE SERÁ CAMBIADO AHORA</p>

Quedaría así

Nota: si aparece un simbolo así < es porque hizo falta una comilla o el cierre de la etiqueta </>

Cambiar política de privacidad

Nota: Siempre escribir dentro de <p;></p>

Para titulos se usa la etiqueta <h1</h1>

Para subtitulos se usa <h3></h3>

Cambiar imágenes

Las imagenes cuentan con una resolución, montar la imagen en la plantilla de ejemplo agregada en su sitio web

	<img src="assets/images/nombreimagen.jpg">

Subir imagenes

NOTA: Si cambian el nombre de la imagen deberan de reescribir el nuevo nombre de la imagen en el recurso del código (src=" ")
